# Phone exporter in the app, panel zoom, and a stable header

## Context

An unattended phone should always have something to show, even when the Mac
is asleep or unreachable. The user also asked to zoom into a single panel with
a double tap, and noticed that paging between "Agents on mike" and "mike"
moved the header's status, dots, and buttons.

## Decision

1. **Phone exporter.** `PhoneExporter` is a minimal Kotlin HTTP/1.1 server on
   `127.0.0.1:19100` only (one daemon thread, request head ≤ 8 KiB, 5 s
   timeout, `GET /metrics` → text format 0.0.4, else 404/400). It shares the
   collector's lifecycle and is scraped as job `phone`, instance `phone`,
   whenever `collector_phone` is true (default). It samples cheap framework
   APIs and small `/proc` and `/sys` files at scrape time only; each source has
   its own try/catch and error counter, and a missing reading drops its family
   rather than reporting zero. Metrics cover battery, thermal status, memory,
   storage, network and Wi-Fi signal, CPU clocks, screen, uptime, and the app's
   and collector's own CPU and memory, plus `android_device_info`. No serials,
   SSIDs, or addresses. `collector=true` alone is now a valid collector setup.
   New permissions: `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` (normal).
2. **Phone dashboard.** `contracts/fixtures/phone-dashboard.json`, generated by
   `tools/gen_phone_dashboard.py` and bundled, reads job `phone` and `up` for
   every collector target, so it shows the phone's state and whether the Mac is
   reachable.
3. **Panel zoom.** A double tap on a panel fills the screen below the header
   with it and redraws it at that size; a double tap or Escape returns. Swipes
   do not switch dashboards and rotation waits while zoomed (C-005 "Panel
   zoom").
4. **Stable header.** In fit the header is one grid line — title (ellipsised) ·
   status (fixed minimum width) · dots · actions — and in the scroll layouts
   the dots sit in a fixed slot left of the actions. Paging between dashboards
   changes only the title text.
5. **Reachable over Tailscale (host setup, outside the repo).** The Mac's
   node_exporter, agenticmac-exporter, and Prometheus listen on all
   interfaces, so the phone can use the Mac's tailnet address away from home.

## Consequences

### Positive

- The phone dashboard always has data while the collector runs.
- One tap pair reads any panel at full size.
- No header movement when paging.

### Negative / risks

- A second loopback listener; other apps on the phone can read its metrics
  (same posture as the collector, C-008).
- Battery current sign and magnitude are as the device reports them.
- The Mac's exporters are unauthenticated on every interface, including the
  tailnet; keep those networks trusted.

## Contracts affected

C-001 v7 (`collector_phone`, targets-or-phone rule), C-005 (Panel zoom), C-007
v8 (phone exporter lifecycle), C-008 v5 (second loopback listener); app-config
schema and fixture.

## Verification

```sh
mise exec -- node --test web/tests/
mise exec -- ./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Emulator: `/metrics` on 19100 returns every family in ~4 ms, `up{job="phone"}`
is 1, `collector_phone=false` closes the port. Browser: a double tap zooms the
chart to 361×787 and redraws it (viewBox 331×688), a second double tap
restores it; header slots keep identical positions across a dashboard switch.
